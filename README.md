# 🛍️ Modern E-Commerce Platform

A feature-rich e-commerce application built to explore modern full-stack patterns, server-side rendering, and headless content management. This project served as a hands-on testing ground to master **Next.js**, **React**, and **Sanity.io** integration.

---

## 🌟 What I Built & Tested

* **Headless Content Management:** Integrated **Sanity.io** Studio as a Content Management System (CMS) to dynamically fetch and display product catalogs, categories, and promo banners.
* **Modern Frontend Architecture:** Built responsive product displays, interactive modal views, and dynamic page routing using **Next.js** and **React**.
* **State & Data Management:** Implemented custom state hooks and API data fetching (GROQ) to seamlessly connect Sanity's backend data with the React storefront.
* **UI/UX Design:** Crafted a clean, mobile-first design focused on fast loading speeds and intuitive store navigation.

---

## 🛠️ Technologies Used

* **Frontend:** React.js, Next.js
* **Backend Content / CMS:** Sanity.io & Sanity Studio
* **Styling & Assets:** CSS3, React Icons
* **Data Fetching:** GROQ (Graph-Relational Object Queries)
